# sunhe
榫合万象
平面古建营造交互作品 —— 以手势/鼠标拖拽榫卯构件，体验传统木构建筑的嵌合之美。

项目简介
《榫合万象》是一款面向零基础用户的传统木构建筑交互体验作品。玩家通过拖拽各类真实造型的榫卯构件（直榫、燕尾榫、卯眼、柱、屋檐等），完成榫头与卯眼的精确嵌合，逐步搭建出传统木构建筑的梁架结构。

作品融入了中国古建筑彩画解锁、营造图鉴、构件文化注释等元素，兼具交互趣味性与传统文化科普价值。

核心功能
两种交互方式
手势操控：基于 MediaPipe Hands 实现摄像头手势识别，食指拇指捏合即可拖拽构件
鼠标操控：按住左键拖拽，支持触摸设备
两阶段任务系统
阶段一 · 引导模式：按顺序完成 3 个子任务
嵌合燕尾榫与燕尾卯
嵌合直榫与直卯
将立柱放置于已嵌合梁下
完成后解锁「自由搭建」入口
阶段二 · 自由搭建：提供 19 个不同尺寸的构件，自由组合搭建传统木构建筑
精细化构件造型
直榫：横木右端矩形凸出榫头，带纵向木纹
燕尾榫：根部窄、端部宽的梯形榫头，带交界线与木纹
卯眼/燕尾卯：左端凹槽精确匹配对应榫头尺寸
柱：带斗状柱头与覆盆柱础的立柱
屋檐：梯形飞檐构件
其他特色
嵌合动画：easeOutBack 缓动，模拟真实"咔嗒"嵌合手感
营造值与彩画解锁：完成搭建积累营造值，解锁和玺龙纹、旋子花瓣等彩画
营造图鉴：查看所有构件的详细介绍与传统文化注释
SVG 导出：将搭建成果导出为矢量插画
重置功能：一键回到初始状态

# 进入项目目录

# 启动本地服务器（自动打开浏览器）

服务器默认运行在 http://localhost:8081/ ，支持 WASM 文件跨域加载。

方法二：使用 VS Code Live Server
在 VS Code 中安装 Live Server 插件，右键 index.html 选择「Open with Live Server」。

注意：由于 MediaPipe 依赖 WASM 文件，必须通过本地服务器访问，直接双击打开 index.html 可能导致 WASM 加载失败。

操作说明
操作	说明
捏合/点击拖拽	拖动手势光标或鼠标选中构件进行移动
靠近嵌合	将榫头靠近对应卯眼，松开后自动吸附嵌合
悬停查看	鼠标/手势悬停在构件上可查看传统文化注释
R 键	重置整个搭建
M 键	切换手势/鼠标模式
底部按钮	重置 / 营造图鉴 / 自由搭建 / 导出插画
技术栈
前端：原生 HTML5 Canvas + JavaScript（无框架依赖）
手势识别：Google MediaPipe Hands（本地离线运行，摄像头数据不上传）
本地服务器：Python 内置 http.server
课程信息
课程：AI 应用素养
性质：课程作业项目
技术特点：零编程基础友好，纯前端实现，手势交互
注意事项
摄像头权限：首次使用需允许浏览器访问摄像头，视频仅在本地用于手势识别，不会上传。
浏览器兼容性：推荐使用 Chrome / Edge 浏览器，确保 WebGL 和摄像头权限正常。
WASM 加载：务必通过本地服务器访问，否则 MediaPipe 的 WASM 文件可能因安全策略被拦截。
键盘 F1 键：若 F1 为系统静音键，不影响本作品操作（未使用 F1 作为快捷键）。
